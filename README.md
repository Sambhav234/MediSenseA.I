## Quick Start

### Windows
```bat
setup.bat
```

### Mac / Linux
```bash
chmod +x setup.sh && ./setup.sh
```

### Manual (any OS)
```bash
# 1. Create virtual environment (recommended)
py -m venv venv
venv\Scripts\activate          # Windows
source venv/bin/activate       # Mac/Linux

# 2. Install dependencies (~2 min, downloads TF)
pip install -r requirements.txt

# 3. Place CSV files in ml/data/ and xray_model.hdf5 in ml/models/

# 4. Train the XGBoost model (~30 seconds)
py ml/train_model.py

# 5. Start the backend
py backend/app.py

# 6. Open frontend/index.html in your browser
```

## API Reference

All responses: `{ "status": "success"|"error", "data": {...}, "message": "...", "timestamp": "..." }`

| Method | Endpoint | Body / Params | Description |
|--------|----------|---------------|-------------|
| GET | `/api/health` | — | System status, model readiness |
| GET | `/api/symptoms` | — | 131 symptom names |
| GET | `/api/diseases` | — | 41 disease classes |
| GET | `/api/model/info` | — | XGBoost metrics, thresholds |
| POST | `/api/predict/symptoms` | `{symptoms:[]}` or `{text:""}` | Top-3 predictions |
| POST | `/api/extract-symptoms` | `{text:""}` | NLP extraction only |
| POST | `/api/chat` | `{message, accumulated_symptoms, force_predict}` | Stateful chat |
| POST | `/api/predict/xray` | `multipart: image=<file>` | X-ray CNN |
| POST | `/api/predict/skin` | `multipart: image=<file>` | Skin detection |
| POST | `/api/predict/multimodal` | `multipart: symptoms/text + image` | Fused result |
| GET | `/api/doctors` | `?specialization=&lat=&lng=&radius_km=` | Doctor list |
| GET | `/api/trending` | — | Health alerts + tips |

### Example
```bash
curl -X POST http://localhost:5000/api/predict/symptoms \
  -H "Content-Type: application/json" \
  -d '{"symptoms": ["high_fever", "chills", "headache", "nausea", "muscle_pain"]}'

# Response: Malaria @ 68.9%, Dengue @ 4.2%, Typhoid @ 3.1%
```

## Safety Layer

The following diseases will NOT be predicted unless specific required symptoms are present:

| Disease | Required symptom(s) |
|---------|---------------------|
| Heart attack | chest_pain, breathlessness, sweating, fast_heart_rate |
| Paralysis | weakness_of_one_body_side, slurred_speech, loss_of_balance |
| AIDS | extra_marital_contacts, receiving_unsterile_injections |
| Alcoholic hepatitis | history_of_alcohol_consumption |
| Piles | pain_in_anal_region, bloody_stool, irritation_in_anus |

## X-Ray Model

Your `xray_model.hdf5`:
- Input: 180×180×3 RGB image
- Output: [NORMAL, PNEUMONIA] softmax probabilities
- Preprocessing: PIL → ImageOps.fit(180,180) → numpy → batch dim
